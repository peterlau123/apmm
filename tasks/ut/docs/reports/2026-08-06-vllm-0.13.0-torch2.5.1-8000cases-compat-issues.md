## 2. 【核心】`_moe_C` 扩展算子注册失效（2,638 个 failed）

### 2.1 症状

`test_fused_marlin_moe` 等 2,638 个用例失败，错误统一：

```
NotImplementedError: Could not run '_moe_C::moe_wna16_marlin_gemm' with
arguments from the 'CUDA' backend. This could be because the operator doesn't
exist for this backend, or was omitted during the selective/custom build process
```

### 2.2 根因链（完整调查）

1. **`_moe_C.abi3.so`（2026-05-12 编译）不含 `moe_wna16_marlin_gemm`**——该算子 2025-12-12 #30254 才合入（函数名从 `moe_wna16_gemm` 改名）→ so 过期
2. **全量重编译受阻**：`pip install -e .` 因 nexus 私有源 setuptools 404 失败；`setup.py build_ext` 因 cmake 需 clone cutlass v4.2.1（无外网 github 超时）失败
3. **JIT 单独编译 marlin 成功**（`build_marlin_ext.py`，15 源文件，纯 torch/CUDA 无 cutlass 依赖）——算子符号进入 so ✅
4. **但注册失败**：`torch.ops._moe_C` 只有 `name`（0 算子）——**`import vllm._moe_C` 成功但 TORCH_LIBRARY 静态注册全部未生效**（连 5-12 旧 so 的 topk_softmax/moe_sum 等 15 个算子都没注册！）
5. **结论**：`_moe_C` 扩展（abi3 stable ABI）在 torch 2.5.1 下**整体注册失效**——非单算子问题，涉及构建链/ABI 层

### 2.3 编译排障过程（记录备查）

| 步骤 | 问题 | 解决 |
|---|---|---|
| pip install -e . | nexus setuptools 80.10.2 404 | 改 setup.py build_ext |
| setup.py build_ext | cmake FetchContent clone cutlass（github 超时） | JIT 只编 marlin（无 cutlass 依赖） |
| JIT 编译 | torch 2.5.1 无 `Float8_e8m0fnu`（torch 2.8+ API） | 条件编译补丁（`#if TORCH_VERSION`） |
| JIT 编译 | ops.cu 无 pybind 入口（PyInit 缺失） | 加 stub 模块（marlin_stub.cpp） |
| JIT 编译 | `-D` 宏需传 extra_cuda_cflags | 修正编译参数 |
| JIT 编译 | ninja 增量缓存混乱（stub 未链接） | 清缓存全量重建 |
| JIT 编译 | 残留进程并发冲突 | 清理脚本（精确 kill） |
| 注册 | 同库双 TORCH_LIBRARY 崩溃 | 改 TORCH_LIBRARY_FRAGMENT |
| 注册 | stub 声明签名不匹配（undefined symbol） | 完整 27 参数签名 |
| **注册** | **`_moe_C` 整体注册空（连旧 so 也空）** | **⚠️ 未解决——环境级问题** |

### 2.4 修复建议（后续立项）

- 方案 A：排查 torch 2.5.1 + abi3 扩展 TORCH_LIBRARY 注册失效根因（可能需重编完整 `_moe_C` 为非 abi3 或换 torch 版本）
- 方案 B：升级 torch（2.8+，同时解决 Float8_e8m0fnu/FP8 cat 问题）——需评估 vllm 0.13.0 兼容性
- 影响面：修复后 2,638 个 marlin + 关联 moe 用例可救回，通过率 52.9% → ~86%

## 3. 其他确定性问题（重跑必挂，记录不重跑）

- **inductor 编译失败 402**：torch.compile 在 H20 + torch 2.5.1 的编译链问题（旧 run 曾用串行 + 提 timeout 救回 22 个）
- **cat FP8 208**：`cat_cuda` 无 Float8_e4m3fn 实现——torch 2.5.1 FP8 支持不完整（升级 torch 可解）
- **float8_e8m0fnu 72**：torch 2.5.1 无 `torch.float8_e8m0fnu` 属性（MXFP4 scale 类型，torch 2.8+ 才有）
- **DeepGEMM 127**：依赖未安装（`deepgemm` 后端不可用）
- **模型 repo 40**：gated 模型需 HF_TOKEN（huggingface 下载）
