## 二、C类兼容性问题详情（重点分析）

### C-1: LoRA 类型签名不兼容

| 项目 | 内容 |
|------|------|
| **问题描述** | `ValueError: infer_schema(func): Parameter lora_a_stacked has unsupported type list[torch.Tensor]` |
| **影响范围** | tests/benchmarks/, tests/utils/, tests/v1/cudagraph/, tests/lora/ 等 16个测试 |
| **根本原因** | PyTorch 2.5.1 不支持 Python 3.10+ 的 `list[torch.Tensor]` 类型签名 |
| **修复方案** | 使用 `typing.List[torch.Tensor]` 或添加 `from __future__ import annotations` |
| **状态** | ✅ 已在之前的分析中确认，需验证修复效果 |

**影响测试示例**:
- `tests/benchmarks/test_random_dataset.py`
- `tests/utils_/test_argparse_utils.py`
- `tests/v1/cudagraph/test_cudagraph_dispatch.py`

---

### C-2: recompile_limit 属性缺失

| 项目 | 内容 |
|------|------|
| **问题描述** | `AttributeError: torch._dynamo.config.recompile_limit does not exist` |
| **影响范围** | tests/kernels/test_flex_attention.py (1个测试) |
| **根本原因** | PyTorch 2.5.1 dynamo 配置没有 `recompile_limit` 属性 |
| **修复方案** | 添加 `hasattr` 检查或条件设置 |
| **状态** | ⚠️ 待修复 |
