## 2. 【核心】`_moe_C` 扩展算子注册失效（2,638 个 failed）

### 2.1 症状

`test_fused_marlin_moe` 等 2,638 个用例失败，错误统一：

```
NotImplementedError: Could not run '_moe_C::moe_wna16_marlin_gemm' with
arguments from the 'CUDA' backend. This could be because the operator doesn't
exist for this backend, or was omitted during the selective/custom build process
```

### 2.2 根因链（完整调查）

1. **`_moe_C.abi3.so`（2026-05-12 编译）不含 `moe_wna16_marlin_gemm`**——该算子 2025-12-12 #30254 才合入（函数名从 `moe_wna16_gemm` 改名）→ so 过期
2. **全量重编译受阻**：`pip install -e .` 因 nexus 私有源 setuptools 404 失败；`setup.py build_ext` 因 cmake 需 clone cutlass v4.2.1（无外网 github 超时）失败
3. **JIT 单独编译 marlin 成功**（`build_marlin_ext.py`，15 源文件，纯 torch/CUDA 无 cutlass 依赖）——算子符号进入 so ✅
4. **但注册失败**：`torch.ops._moe_C` 只有 `name`（0 算子）——**`import vllm._moe_C` 成功但 TORCH_LIBRARY 静态注册全部未生效**（连 5-12 旧 so 的 topk_softmax/moe_sum 等 15 个算子都没注册！）
5. **结论**：`_moe_C` 扩展（abi3 stable ABI）在 torch 2.5.1 下**整体注册失效**——非单算子问题，涉及构建链/ABI 层

### 2.5 【修复成功】JIT 完整重编译 `_moe_C`（2026-08-07）

**结果**: 2,638 个 marlin 用例全部救回（重跑 2,950 → 2,638 passed / 312 failed），
8000 用例通过率 **52.9% → 85.9%**。

**修复链（11 个 blocker 攻破）**:

| 步骤 | 问题 | 解决 |
|---|---|---|
| 1 | 全量重编译缺依赖（无外网） | 本机 GitHub 下载 5 个依赖本地化：cutlass v4.2.1 / triton v3.5.0 / FlashMLA / qutlass / googletest（`/gpfs/gcsp/liuxin/vllm-deps/`） |
| 2 | triton 编译需 MLIR（LLVM 级） | ⛔ 全量编译死路 → **转 JIT 只编 `_moe_C`**（23 源文件纯 torch/CUDA，绕开 triton） |
| 3 | cutlass 头依赖（permute_unpermute） | 本地 cutlass-src include 路径 |
| 4 | JIT 默认禁用 half 转换宏 | `-U__CUDA_NO_HALF_CONVERSIONS__` 等取消 |
| 5 | PyInit 重复（stub + torch_bindings 自带） | 去掉 stub |
| 6 | 注册库名（cflags 无 `_moe_C` 宏） | `TORCH_LIBRARY(_moe_C, m)` 硬编码 |
| 7 | PyInit 名不匹配（`PyInit_moe_marlin_custom`） | `REGISTER_EXTENSION(_moe_C)` 硬编码 → `PyInit__moe_C` |
| 8 | vllm 只加载 `vllm/_moe_C.abi3.so` | 新 so 替换（备份 `.bak-20260512`） |

**验证**: `import vllm._moe_C` → `marlin: True`；实测 `test_fused_marlin_moe` **1 passed**。

**工具沉淀**: `build_moe_c_full.py`（JIT 完整 _moe_C 编译）/ `rerun_marlin.py`（批量重跑）
/ `full_rebuild.sh`（全量编译依赖本地化）/ 共享 vllm 源码 patch（`ops.cu` Float8 条件编译、
`torch_bindings.cpp` 注册库名 + PyInit 硬编码，均含备份）。

**注意**: 新 so 为 JIT 编译产物（非 abi3 官方构建），容器重建后需重编；vllm 源码
patch 与 so 替换仅本环境生效（环境只有用户使用）。
