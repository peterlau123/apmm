## 一、已发现兼容性问题

### C-1: LoRA 类型签名不兼容 ✅ 已修复

| 项目 | 内容 |
|------|------|
| **问题描述** | `ValueError: infer_schema(func): Parameter lora_a_stacked has unsupported type list[torch.Tensor]` |
| **影响范围** | tests/lora/, tests/distributed/, tests/quantization/, tests/compile/, tests/benchmarks/, tests/plugins_tests/, tests/tool_use/, tests/utils_/, tests/v1/ |
| **根本原因** | PyTorch 2.5.1 不支持 `list[torch.Tensor]` 类型签名，需使用 `typing.List[torch.Tensor]` |
| **修复方案** | 添加 `from __future__ import annotations` 或使用 `typing.List` |
| **状态** | ✅ 已修复并提交 |

---

### C-2: DeepSeek torch_compile 参数错误 ✅ 已修复

| 项目 | 内容 |
|------|------|

| **影响范围** | DeepSeek 相关测试 |
| **根本原因** | JSON 格式错误 |

| **Commit** | `15565df57` |
